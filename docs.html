Alchemist Lab

An experimental onchain workshop preparing its first public trial.

The laboratory is pre-launch. No token, contract address, or mint is live.

Alchemist Lab is currently collecting early operator registrations for its genesis registry. Registration records an X handle and an EVM address on the visitor's device while the external registry is being prepared.

Request access

  1. Open the laboratory landing page.
  2. Select Request clearance.
  3. Enter your X handle and a valid 42-character EVM address.

Use an address you control. Never enter a seed phrase or private key.

Genesis registry

The current teaser stores submissions in browser localStorage. It does not send data to a server or guarantee allowlist access.

  • X handles accept up to 15 letters, numbers, or underscores.
  • EVM addresses must begin with 0x followed by 40 hexadecimal characters.
  • Signing a message is not required during this trial.
